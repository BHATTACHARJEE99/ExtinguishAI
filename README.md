# ExtinguishAI
ExtinguishAI is a scalable, AI-driven drone surveillance system capable of autonomously detecting and suppressing wildfires before escalation. Trained machine learning models on historical wildfire datasets and environmental indicators such as temperature, wind speed, and humidity for predictive analysis, enabling early-stage fire detection with high accuracy. Integrated computer vision to identify fire flickers invisible to satellites, reducing false alarms and response delays.
Designed and simulated operations of a 6-drone system with high-resolution thermal cameras, LiDAR sensors, and Starlink-powered real-time data transmission—covering 2.36 million square miles daily with a deployment cost of $448,000, significantly outperforming traditional camera networks costing up to $50 million. Incorporated solar-powered, weatherproof storage units with battery backups to ensure 24/7 operation in remote areas.
Engineered autonomous navigation, AI-based fire retardant deployment, and swarm coordination to improve suppression efficiency. Delivered a mobile app prototype for real-time alerts and manual drone control. Projected environmental and financial benefits include minimizing deforestation, protecting biodiversity, reducing carbon emissions, and potentially averting up to $53.8 billion in wildfire damages annually.
